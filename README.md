# 💰 Finance Tracker

**Полнофункциональное веб-приложение для управления личными финансами**

Учебный Full-stack проект, разработанный в рамках портфолио студента направления «Разработка программного обеспечения (Full-stack разработка)».

---

## 📋 Описание проекта

Finance Tracker — это современное веб-приложение для учёта личных финансов. Позволяет отслеживать доходы и расходы, анализировать траты по категориям, устанавливать бюджеты и экспортировать данные.

### 🎯 Цель проекта
Демонстрация навыков Full-stack разработки: от проектирования базы данных до развёртывания в Docker-контейнерах.

## 🚀 Инструкция по запуску

### Предварительные требования
- Node.js 18+
- PostgreSQL 16+ (или Docker)
- npm или yarn

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/finance-tracker.git
cd finance-tracker
```

### 2. Установка зависимостей Frontend
```bash
npm install
```

### 3. Настройка Backend
```bash
cd server
npm install

# Создать .env файл
cp .env.example .env
# Отредактировать DATABASE_URL и JWT_SECRET в .env
```

### 4. Настройка базы данных
```bash
# Генерация Prisma Client
npx prisma generate

# Запуск миграций
npx prisma migrate dev --name init

# (Опционально) Открыть Prisma Studio для просмотра данных
npx prisma studio
```

### 5. Запуск в режиме разработки

**Frontend** (порт 5173):
```bash
npm run dev
```

**Backend** (порт 3001):
```bash
cd server
npm run dev
```

### 6. Docker-развёртывание

```bash
# Запустить все сервисы
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановить
docker-compose down

# Остановить и удалить данные
docker-compose down -v
```

После запуска:
- Frontend: http://localhost:5173
- Backend API: http://localhost:3001
- PostgreSQL: localhost:5432
